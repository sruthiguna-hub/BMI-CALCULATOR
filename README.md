# BMI Calculator

## Description
A Python GUI application built using Tkinter to calculate Body Mass Index (BMI).

## Features
- User enters Name, Weight, and Height
- Calculates BMI
- Displays BMI category
- Saves the result to output.txt

## Technologies Used
- Python
- Tkinter

## How to Run
1. Open the project in VS Code.
2. Run:
   ```
   py main.py
   ```
3. Enter the required details.
4. Click **Calculate BMI**.
